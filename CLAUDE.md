# Automation Studio: project notes for Claude

Studio for X/Twitter and YouTube content about automation and trading automation. Films are canvas pages in `studio/films/<name>/` rendered by `studio/render.mjs` (Playwright frames piped to ffmpeg, BT.709, 60 fps for the masters). Audio is generated by `studio/audio*.py`. Masters go in `out/` (keep under 100 MB). Inputs for new films: `./brand`, `./refs`, `./screens`. Prompt library for inspiration: `refs/awesome-opus5-5-videos/` (703 prompts of code-made videos, `data/videos.json` is searchable by category/tech; MIT, credit the creator when a prompt is reused; the videos themselves are not included).

## Which baseline to start from
- **Any new explainer film:** start from `STUDIO_BASELINE.md` / the `explainer-film` skill. The owner supplies topic, audience, outcome and length; fill `{{TOPIC}}`, `{{AUDIENCE}}`, `{{OUTCOME}}`, `{{SECONDS}}` and run it.
- **Frank369 trading videos:** use `BASELINE.md` / the `frank369-video` skill instead. (Neither exists yet: until the owner provides them, follow the existing `night-desk` film and the Frank369 rules below.) Its rules still apply there: the disclaimer, never invent Frank369 rules, and stills-first approval.

## General rules (all work)
- Disclaimer on every trading-related video: "Not financial advice. For educational purposes only. Simulated data." Small, centred at the bottom, light grey on a dark backing, visible for the whole video.
- Never invent trading rules (ICT or Frank369). If a rule, formula or definition is unclear, ask the owner before building. All numbers shown are simulated or sourced and labelled as such.

## Music (all videos)
- Default soundtrack for every video: `assets/music/heroes_tonight.mp3` (Janji - Heroes Tonight feat. Johnning, NCS). Use ONLY the supplied music: no generated tracks and no generated sound effects. Cut on the beat, put the track's drop on the video's key moment, fade out under the end card, mix to about -14 LUFS with a plain gain change, no clipping.
- Every export gets a `DESCRIPTION.txt` and a README credit line: "Music: Janji - Heroes Tonight (feat. Johnning) [NCS Release] — ncs.io/ht".
- Other tracks only if the owner supplies the files (the Drive folder "Music for F369Ai" was not readable from this session). `assets/music/im_so_lucky_hardtekk.mp3` (Jeff Germita - IM SO LUCKY HARDTEKK) is the track chosen for the Nasdaq Flash video; its licence was not stated, so confirm before publishing and credit as "Music: Jeff Germita — IM SO LUCKY (HARDTEKK)".

## Real data only
- Use only real stocks (tickers) and real automations the owner says they have actually used. Never invent a ticker, automation, result or number. If it is not provided, ask. Simulated numbers must be labelled as simulated.

## Frank369 videos
- Stills-first approval: render 3 still frames (start, middle, climax), show them, wait for approval, then do the full render with audio, keep the file under 100 MB, commit to `out/` and push.

## Skills (installed in `.claude/skills/`)
- `explainer-film` (this studio's general baseline), plus `frontend-design`, `canvas-design`, `algorithmic-art` from github.com/anthropics/skills.
- From github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT): `ui-ux-pro-max` (searchable styles, palettes, font pairings, UX rules), `ui-styling`, `design`, `design-system`, `brand`, `banner-design`, `slides`. Their logo/icon/background scripts call external image APIs (Gemini etc.) and need API keys this environment does not have; the local search scripts work offline.
- Remotion is NOT used in this project (no package.json, renders are canvas + ffmpeg), so the Remotion skills are not installed. If the project ever adopts Remotion, run `npx skills add remotion-dev/skills` and use `remotion-best-practices` from then on.
- For every video or design change, apply `frontend-design` (distinctive, intentional aesthetic direction, typography, no templated defaults) and `algorithmic-art` (seeded, parameter-driven generative motion; every frame a pure function of t) before writing code. Use `canvas-design` for static posters and image cards. If `remotion-best-practices` is installed, follow it for any Remotion work as well.
